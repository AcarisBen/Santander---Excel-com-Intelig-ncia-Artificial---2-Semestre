# PROJETO 2

# 📊 Organizador de Documentos – Imposto de Renda (Excel)

Este projeto consiste em um **organizador de documentos para o Imposto de Renda**, desenvolvido em **Excel**, com o objetivo de centralizar e facilitar o controle das informações necessárias para a declaração anual.

A planilha foi pensada para ser simples, prática e acessível, permitindo que o usuário reúna todos os dados em um único arquivo ao longo do ano, evitando retrabalho e esquecimentos no período da declaração.

---

## 🗂️ Estrutura da Planilha

O arquivo é composto por **três abas principais**, cada uma com uma função específica:

### 1️⃣ Dados do Contribuinte
A primeira planilha é destinada ao preenchimento dos **dados pessoais e cadastrais**, como:
- Informações básicas do contribuinte
- Dados necessários para identificação na declaração
- Informações gerais que não variam mensalmente

Essa aba funciona como a base da declaração.

---

### 2️⃣ Informes Bancários
A segunda planilha é voltada para o registro dos **informes de rendimentos fornecidos pelos bancos**, como:
- Rendimentos de contas correntes e poupança
- Aplicações financeiras
- Outras informações bancárias relevantes

Dessa forma, todos os informes ficam organizados em um único local.

---

### 3️⃣ Notas Mensais
A terceira planilha é dedicada ao controle das **notas e despesas mensais**, permitindo:
- Registro mês a mês das despesas
- Organização cronológica dos comprovantes
- Facilidade na conferência dos valores ao final do ano

Essa aba ajuda a manter o controle contínuo ao longo do exercício fiscal.

---

## 🎯 Objetivo do Projeto

- Facilitar a organização dos documentos do Imposto de Renda  
- Reduzir erros e esquecimentos na declaração  
- Centralizar informações pessoais, bancárias e mensais  
- Servir como apoio tanto para uso pessoal quanto para estudos/prática em Excel  

---

## 🛠️ Tecnologias Utilizadas

- **Microsoft Excel**
- Organização manual de dados (sem macros ou automações avançadas)

---

## 🚀 Como Utilizar

1. Faça o download do arquivo Excel disponível neste repositório
2. Preencha a aba **Dados do Contribuinte**
3. Insira os dados dos **Informes Bancários**
4. Atualize mensalmente a aba de **Notas Mensais**
5. Utilize as informações organizadas no momento da declaração do Imposto de Renda

---

## 📌 Observações

Este projeto tem caráter **organizacional e educacional** e não substitui a orientação de um contador ou profissional especializado.

---

## 📄 Licença

Este projeto é de uso livre para fins pessoais e educacionais.

# PROJETO 3


# 📈 Dashboard Analítico – Banco de Dados Fictício

Este projeto consiste no desenvolvimento de um **dashboard analítico**, construído a partir de um **banco de dados fictício**, com o objetivo de explorar, organizar e visualizar informações de forma clara e intuitiva.

O foco do projeto é transformar dados brutos em **insights visuais**, simulando um cenário real de análise de dados, como os encontrados em ambientes corporativos e acadêmicos.

---

## 🗄️ Base de Dados

A base utilizada neste projeto é **totalmente fictícia**, criada com fins educacionais e demonstrativos, simulando dados reais para análise.

Ela foi estruturada de forma a permitir:
- Análises comparativas
- Visualização de tendências
- Consolidação de métricas relevantes
- Exploração de diferentes dimensões dos dados

---

## 📊 Estrutura do Dashboard

O dashboard foi organizado para facilitar a leitura e a tomada de decisão, contendo:

- Indicadores principais (KPIs)
- Gráficos comparativos
- Visualizações temporais
- Segmentações e filtros para análise dinâmica dos dados

Cada elemento foi pensado para apresentar as informações de forma objetiva e acessível.

---

## 🎯 Objetivo do Projeto

- Praticar conceitos de análise e visualização de dados  
- Simular um cenário real de tomada de decisão baseada em dados  
- Transformar dados fictícios em informações relevantes  
- Demonstrar organização, clareza e narrativa visual  

---

## 🛠️ Tecnologias Utilizadas

- Ferramenta de visualização de dados (ex: Excel / Power BI / similar)
- Banco de dados fictício
- Gráficos e indicadores visuais

---

## 🚀 Como Utilizar

1. Faça o download dos arquivos disponíveis neste repositório
2. Abra o dashboard na ferramenta indicada
3. Explore os filtros e segmentações disponíveis
4. Analise os indicadores e gráficos apresentados

---

## 📌 Observações

Este projeto utiliza dados fictícios e tem finalidade **educacional e demonstrativa**, não representando informações reais de empresas, pessoas ou organizações.

---

## 📄 Licença

Este projeto é de uso livre para fins educacionais e de estudo.
